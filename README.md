# Creative Engineer Portfolio

A dark, interactive, responsive portfolio starter built with Next.js, TypeScript, CSS and Framer Motion.

## Run locally

Requirements: Node.js 18.17+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.


## Deploy

Push the project to GitHub and import the repository into Vercel. The default Next.js build settings should work.

## Notes

- The site uses Google Fonts via CSS import; remove the import or self-host fonts if you need fully local font assets.
- Framer Motion animations respect `prefers-reduced-motion`.
- Contact form is intentionally not included; the contact CTA uses email links.
